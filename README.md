# Personal Website (scaffold)

This is a minimal static scaffold for a personal website with pages for Services, CV, Projects, Trainings, and Articles.

How to preview locally:

1. Open a terminal in this folder.
2. Run a simple static server, for example with Python 3:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

Alternatives:
- Use the Live Server extension in VS Code.
- Deploy to GitHub Pages by pushing to a repository and enabling Pages.

Next steps suggestions:
- Replace placeholder text with your content and links.
- Add images in an `assets/` folder and update pages.
- Add a contact form or integrate a third-party contact provider.
