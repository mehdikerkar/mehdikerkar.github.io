## 🚀 Key Features & Interactive Systems

* **💱 Real-Time Currency Switcher (DZD ⇋ EUR):**
  - Integrated into `training.html` across all three languages.
  - Allows prospective trainees and corporate clients to toggle prices between Algerian Dinars (DZD) and Euros (EUR) instantly.
  - Automatically persists user preference using `localStorage`.

* **🔍 Instant Search & Live Category Filtering:**
  - Client-side search engine in `projects.html` and `training.html`.
  - Instant zero-latency filtering by domain tags (`OT/ICS`, `GRC/ISO`, `Technical/Pentest`, `Audit`) and search terms without external API round-trips.

* **⭐ 20 Verified Industry Endorsements:**
  - Comprehensive reference showcase in `about.html` featuring authenticated testimonials from senior executives and clients across **CGI, Sonatrach, PwC, EY, KPMG, Ooredoo, Djezzy, and national infrastructure operators**.
  - Includes full credentials, roles, and project context for each reference.

* **📺 Curated Media Hub & Conference Keynotes:**
  - Standardized video showcases in `community.html` featuring authenticated conference recordings and interviews (OWASP Tunisia, Shellmates ESI, Radio Chaîne 3 Médiatics, CTO Forum Algeria, and ISA Webinars).

* **📱 Mobile-First Responsive Design:**
  - Ultra-compact header top-bar optimized for mobile viewports (≤ 768px and ≤ 420px) preventing button deformation.
  - Accessible drawer navigation, smooth animated transitions, and touch-optimized interactive touch targets.

* **🛡️ Trilingual Auto-Detect 404 Page:**
  - Smart error page (`404.html`) that parses browser locale or URL context to present localized recovery paths (EN, FR, AR).
  - Dynamic relative-path resolution supporting both GitHub Pages root hosting and local file inspection.

## 🛠️ Technology Stack & Performance Standards

| Layer | Implementation Details |
| :--- | :--- |
| **Markup & Semantics** | Semantic HTML5, WAI-ARIA accessibility landmarks, WCAG 2.1 AA compliant color contrasts. |

## 💻 Local Development & Testing

This project requires **zero build tools, compilers, or package managers**. Any standard static web server can serve the files.

### 1. Clone the Repository
```bash
git clone https://github.com/mehdikerkar/mehdikerkar.github.io.git
cd mehdikerkar.github.io
```

### 2. Run Locally

#### Using Python (Built-in Server)
```bash
# Python 3.x
python -m http.server 8000
```
Open `http://localhost:8000` in your web browser.

#### Using Node.js (Optional)
```bash
npx serve .
```

#### Using VS Code
Install the **Live Server** extension and click **"Go Live"** from the bottom status bar.
