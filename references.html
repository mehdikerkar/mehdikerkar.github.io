STANDARDS & FRAMEWORKS

Industry Standards & Best Practices

  • ISA/IEC 62443 (Industrial Cybersecurity) — International standard for securing industrial automation and control systems
  • NIST Cybersecurity Framework (CSF) — U.S. standard for managing cybersecurity risks across organizations
  • ISO/IEC 27001:2022 (Information Security Management) — Global standard for information security systems and controls
  • ISO/IEC 42001:2024 (AI Risk Management) — Standard for AI and machine learning risk management
  • ISO 22301 (Business Continuity Management) — Framework for organizational resilience and disaster recovery
  • MITRE ATT&CK Framework — Adversary tactics and techniques based on real-world cyber threat intelligence
  • OWASP Top 10 (Web Application Security) — List of the most critical web application security risks
  • Purdue Enterprise Reference Architecture (PERA) — Industrial network architecture model for OT/IT integration
  • NIST Supply Chain Risk Management — Framework for managing third-party cybersecurity risks
